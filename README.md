# Stellar Stays

Static luxury hotel booking landing page for Stellar Stays.

## Features

- Responsive hotel landing page
- Room filtering and booking modal interactions
- Gallery, testimonials, contact, and payment sections
- Live-server development workflow

## Getting Started

Install dependencies:

```bash
npm install
```

Start the local development server:

```bash
npm start
```

The app will run at `http://localhost:3000`.
